# 记忆库管理（memory-hub）Skill

自动扫描本机**所有AI工具**的会话记忆（ZCode/ClaudeCode/豆包/Codex/Cursor/Windsurf 等24个），按统一标准提炼（成果/待办/知识点/问题解决/经验/决策），写入第二大脑记忆库（AI会话记忆 / 项目经验库 / 能力经验库），沉淀**跨AI经验**。

## 特性
- 🔍 **纯自动发现**：扫描本机用户目录+AppData，自动识别所有安装过的AI（零手动配置，新AI在 `knowledge/ai_sources.md` 加一行即可）
- 📋 **统一提炼标准**：结论（成果）/待办/知识点/问题与解决/经验/决策 + 标记（🔴问题/⭐经验/💡薄弱点/🧭偏好）
- 🏗️ **三层记忆库**：明细归AI（AI会话记忆）、经验归项目（项目经验库）、方法归能力（能力经验库）
- 📦 **开箱即用**：`install.py` 一键安装——生成配置、建库骨架（使用指南/首页/总索引/聚合模板/捕捉箱），已存在文件不覆盖
- 🔒 **隐私安全**：`config.json`（本机路径）与 `scripts/memory_hub_state.json`（会话清单）均已 gitignore，不随仓库分发；库内容禁止外发，🔒敏感标注
- 📉 **省token**：分层读取（总索引→摘要区→全文），日常调用仅500-800 tokens

## 安装使用
```bash
# 1. 放入技能的 skills 目录（如 ~/.zcode/skills/ 或 ~/.claude/skills/）
git clone https://github.com/WCCong1213/memory-hub.git ~/.zcode/skills/记忆库管理

# 2. 运行安装向导（填记忆库路径 + 选择是否装 Obsidian）
python install.py

# 3. 对AI说"整理记忆"即自动执行
```

安装完成后，记忆库根目录会得到（全部可编辑，重跑不覆盖）：

```
📖 记忆库使用指南.md          # AI 入口：读取/写入规则
🏠 记忆库首页.md              # 人的入口：三个库 + 常用链接
📥 捕捉箱.md
项目经验库/📋 项目总索引.md
项目经验库/_模板/📊 项目经验聚合模板.md
能力经验库/📋 经验总索引.md
能力经验库/_模板/📊 经验聚合模板.md
```

## 分享给别人

只分发本仓库（引擎 + 空模板），**不分发库内容**：

1. 对方 clone 本仓库到自己的 skills 目录
2. 运行 `python install.py`，填自己的记忆库路径
3. 对方得到一个空库骨架，内容靠他自己的会话长出来

`config.json`、`scripts/memory_hub_state.json`、`__pycache__`、`*.bak-*` 已在 `.gitignore` 中，不会被推上去。提交前可用下面命令自查有没有私人路径混入：

```bash
git grep -n -I -E "C:\\\\Users|D:\\\\" -- ':!*.md' || echo "无本机路径"
```
