# 记忆库管理（memory-hub）Skill

自动扫描本机**所有AI工具**的会话记忆（ZCode/ClaudeCode/豆包/Codex/Cursor/Windsurf 等24个），按统一标准提炼（成果/待办/知识点/问题解决/经验/决策），写入第二大脑记忆库（AI会话记忆 / 项目经验库 / 能力经验库），沉淀**跨AI经验**。

## 特性
- 🔍 **纯自动发现**：扫描本机用户目录+AppData，自动识别所有安装过的AI（零手动配置，新AI在 `knowledge/ai_sources.md` 加一行即可）
- 📋 **统一提炼标准**：结论（成果）/待办/知识点/问题与解决/经验/决策 + 标记（🔴问题/⭐经验/💡薄弱点/🧭偏好）
- 🏗️ **三层记忆库**：明细归AI（AI会话记忆）、经验归项目（项目经验库）、方法归能力（能力经验库）
- 📦 **插件式体验**：`install.py` 一键安装（自动创建记忆库骨架），可配置路径、可打包分享
- 🔒 **隐私安全**：config.json 不公开（本机路径），库内容禁止外发，🔒敏感标注
- 📉 **省token**：分层读取（总索引→摘要区→全文），日常调用仅500-800 tokens

## 安装使用
```bash
# 1. 放入技能的 skills 目录（如 ~/.zcode/skills/ 或 ~/.claude/skills/）
# 2. 运行安装向导（填记忆库路径+选择是否安装Obsidian）
python install.py
# 3. 对AI说"整理记忆"即自动执行
```

## 目录结构
```
记忆库管理\
├── SKILL.md                  # 技能规则（触发词：整理记忆/记忆搜索/记忆回顾）
├── install.py                # 安装向导（自动创建记忆库骨架）
├── config.json.example       # 配置模板（记忆库路径，零硬编码）
├── knowledge\
│   ├── ai_sources.md         # AI数据源知识库（24个AI：位置+格式+解析）
│   ├── 记忆库使用指南模板.md  # 复制到记忆库根目录的入口指南
│   └── 模板\会话笔记模板.md   # 统一提炼模板
└── scripts\
    ├── scan_ai_memories.py   # 自动扫描+增量检测
    └── append_execution.py   # 写入项目执行史
```

## 记忆库结构（第二大脑）
```
D:\第二大脑\
├── AI会话记忆\<AI名>\    # 会话笔记（明细层）
├── 项目经验库\<项目>\    # 跨AI执行史（日期|AI|任务|问题|解决|经验）
├── 能力经验库\<能力>\    # 跨项目方法论
└── 📥 捕捉箱.md          # 临时想法
```
