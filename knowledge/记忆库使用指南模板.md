# 📖 第二大脑记忆库使用指南

> **给任何AI的入口文件**：无论你是什么AI工具（ZCode/Claude Code/豆包/Gemini/其他），接手任何任务前，先读本文件，即可使用本知识库的全部记忆与经验。

## 二、读取流程（AI接手任务时）

**核心模式：先检索经验，再执行任务**——收到用户任何问题/任务时：

1. **先检索**：运行 `scripts/search_memory.py "问题关键词"`（或关键词搜索聚合页）——查记忆库有没有同类问题链经验
2. **引用经验**：有同类经验 → 按"问题链经验卡"组织回复（引用成功路径+避开已知难点），回复中标注"（依据记忆库·XX库·问题链N）"；无同类经验 → 专业执行并记录过程
3. **读本指南**（了解结构）
4. **判断任务归属**：
   - 属于哪个项目（考试/客户/工作事项）→ 读 `项目经验库\项目名\📊 项目经验聚合.md`（问题链经验）
   - 需要通用能力 → 读 `能力经验库\对应能力\📊 经验聚合.md`（问题链经验卡）
   - 需要细节 → 按问题链轮次/日期/AI跳转 `AI会话记忆\对应AI\`
5. **CPA复习专项**：先读 `AI会话记忆\ZCode\D_2026CPA_02_CPA战略_错题集\📊 项目知识聚合.md` + 《CPA复习经验总结.md》+ 《易忘考点清单.md`

## 三、写入流程（AI会话结束时）——总结经验的标准格式

**经验 = 问题链**（用户反复追问/纠正的每一轮=一个难点，全程提炼）：

### 问题链经验卡格式（写入聚合页）
```
### 问题链N：<问题主题>
**问题起点**：用户第一次问什么
**执行过程（多轮延伸）**：
  - 第1轮：我做了什么 → 用户反应
  - 第2轮：用户追问/纠正"原话" → 🔴难点：xxx → 我调整"xxx"
  - ……（每一轮用户追问都记录）
**最终结果**：✅成功 / ❌失败（关键点）
**难点总结**：①xxx ②xxx（用户反复追问的点）
**复用要点**：未来同类问题怎么直接做
```

### 写入步骤
1. **更新项目经验库**：向对应项目的 `📊 项目经验聚合.md` 追加问题链经验卡（成功/失败都记）
2. **更新能力经验库**：可跨项目复用的经验 → `能力经验库\对应能力\`（同样用问题链格式）
3. **更新状态**：项目聚合页"当前状态"节
4. **明细留存**：完整会话提炼成笔记存 `AI会话记忆\本AI\`

### 经验卡维护规则（筛选+归纳+持续更新）
1. **筛选（删无效轮次）**：提炼时只保留**推动问题解决的有效轮次**；"不了了之"（无进展/死胡同/重复啰嗦）的轮次**删除**，不写进经验卡
2. **归纳（非原话堆砌）**：每轮提炼成"这轮解决了什么"（用户追问→难点→调整方向），不是贴对话原文
3. **持续更新（不是无限追加）**：同一问题再次遇到 → **更新**经验卡：新解法替换旧解法、新难点追加、过时内容删除——经验卡始终保持"当前最优版本"
4. **维护时机**：每次该问题相关任务完成后，检查并更新对应经验卡；项目结束后归档

### 沉淀闭环
任务完成 → 有经验卡→归纳更新（筛选+更新）；新问题→创建新问题链 → 下次遇到先检索命中 → 经验越用越准（始终是最优版本）

### 效果衡量（效率与成功率验证）
1. **效率提升**：同类问题再次处理时，对比首次轮次/耗时（如首次16轮→复用后3步）——在经验卡记录"复用效果"
2. **成功率提升**：复用经验后是否一次成功——**复用仍失败 → 经验卡必须更新**（补新难点/换新解法）
3. **经验卡状态标记**：`复用N次·成功率X%`——持续未复用的经验卡标记"待验证"，多次复用成功的升为"金牌经验"

## 四、分类判定标准

> **"这个经验，换一个项目还能不能用？"**
> - 能 → 能力经验库（如：Excel自动化方法、审计底稿套路）
> - 不能 → 项目经验库（如：CPA战略错题、某客户具体回复）

**跨库去重规则**：同类经验出现两处时——**能力经验库为主**（完整问题链卡），项目经验库只保留"案例引用"（一行链接指向能力库经验卡），避免重复维护

## 五、与用户配合的触发词

用户说以下任何一句，即执行读取流程：
- "读一下第二大脑" / "看下记忆库" / "先看使用指南"
- "按照记忆库的要求" / "把这段经验记进去"

## 六、维护原则

- 明细归AI、经验归项目、方法归能力
- 会话记录当天同步（防止AI本地记录丢失）
- 无关紧要内容（闲聊/购物/空会话/隐私）清洗过滤，不导入

# 附：使用规范升级（v1.1，2026-08-18）

## 七、AI执行者改进要点

### 1. 定位：先读总索引
- `项目经验库\📋 项目总索引.md`——项目名|目录|状态|最近更新，10秒定位
- 能力经验库4个能力域固定（Excel自动化/审计实务/AI工具/学习记忆），无需索引

### 2. 读取：分层读（省token）
- 聚合文件顶部有**摘要区**（当前状态+最近3条执行）→ 先读摘要，需要细节再读全文
- 执行史滚动归档：保留近期约20条，更早的移入 `归档\`（文件名加日期）

### 3. 写入：用脚本（格式统一）
```bash
python D:\第二大脑\scripts\append_execution.py \
  --project "项目名" --date 2026-08-18 --ai "ZCode" \
  --task "任务" --problem "问题" --solution "解决" --experience "经验"
```
- 脚本自动插入执行史表末行，防格式错乱/并发覆盖
- 无法运行脚本时（云端AI），按示例手动追加：
`| 2026-08-18 | ZCode | 任务 | 问题 | 解决 | 经验 |`

### 4. 明细目录规则（跳转用）
`AI会话记忆\<AI名>\<项目名>\`——如 `AI会话记忆\ZCode\D_2026CPA_02_CPA战略_错题集\`

### 5. ⚠️ 隐私保护（强制）
- 本库含审计项目底稿信息、个人资料——**禁止将库内容外发**（不粘贴到联网服务、不上传）
- 敏感条目标注 🔒，AI 遇到 🔒 内容不得复制转发
