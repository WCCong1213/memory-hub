## 填写规则
1. **🔴问题→✅解决**：每个执行问题必须写解决方式（问题无解决=不记）
2. **⭐经验**：必须是一句话可复用结论（如"已掌握考点必须做题验证"），禁止"完成了"这类空话
3. **💡薄弱点**：用户反复问/反复错的，标 💡 并写"下次重点"
4. **🧭偏好**：用户确认的偏好写入 frontmatter `preferences` 字段
5. 无关紧要内容（闲聊/购物/空会话）不提炼

## 填写示例
- **结论（成果）：** 完成Day4复习（S档4V✅、B档12组全过）、建成风险应对弹药库
- **待办：** 次日重做102（先回看错因）；易忘清单31条开场过
- **知识点：** 运营风险13类口诀"组人责文采资售研工外合传系"；风险分类五问定大类
- **问题与解决：** 🔴 风险应对记不住 → ✅ 三级表+动作卡分层记
- **经验：** ⭐ 名称记原文/表现抄材料/应对记关键词
- **决策：** 确认记忆偏好=底层逻辑串联（不用故事）

# 问题链经验卡模板（升级版 · 项目/能力经验库用）

> 适用：**有难度的任务**（用户反复追问/纠正≥2轮、执行有波折）才写完整问题链卡；一次通过无波折的只记一句话结论。
> 目标：把"发生过的事"变成"下次能直接用的能力"——**成功率↑（完整最优解）+ token↓（读摘要层即可执行）**。

```markdown
### 问题链N：<标题>

**触发场景**：什么情况下会碰到这个问题（= 检索关键词，AI搜索时据此命中）

**目标**：当时想达到什么效果（预期）

**执行过程（多轮）**：
- 第1轮：...（保留问题→执行→用户反馈的真实顺序）
- 第2轮：**用户纠正/追问"..."** → 调整为...（每轮用户纠正=一个难点，必须记录）
- ...

**结果**：✅成功 / ❌失败 / 🟡部分成功 + 验证次数（第1次/多次验证/待验证）

**根因（why）**：卡住的根本原因（用5Why追到根，不是现象描述）

**复用（if-then）**：
- ✅ 保持：下次遇到<触发场景> → 直接做<成熟做法>
- 🔧 改进：<可做得更好的点>
- ⛔ 停止：<不要再做的做法>
- 🆕 尝试：<下一步可试的方向>

**边界**：适用条件 + 反例（什么情况不适用/不能套用）

**链接**：→ 相关笔记/源文件/其他经验卡（双链）
```

## 提炼判断标准（写卡前先判断）
1. **有难度才配问题链卡**：用户反复追问/纠正≥2轮，或执行失败过 → 完整卡
2. **一次通过无波折** → 只写一句话结论（⭐），不写问题链卡
3. **每轮用户纠正 = 一个难点**，缺了难点=不合格卡（质检抽查项）
4. **必须回答 why**：只记 what/how 不记 why = 存档，不是经验
